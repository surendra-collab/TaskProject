# Project Setup and Run

## Steps

1. Download or clone this project code.
2. Open terminal in the project folder.
3. Run:

```bash
composer update
```

4. Then run:

```bash
php artisan serve
```

The app will start on a local development URL (usually `http://127.0.0.1:8000`).
